This is a lightweight casting app that allows users to stream any ExoPlayer-supported video format to a TV by entering a video URL. The app requires no server or storage, making it simple to import, build, and launch instantly.

Features
Supports all ExoPlayer-compatible video formats.
Simple UI with a text input for video URLs.
Direct casting to TV using existing cast libraries.
No server or storage dependencies.

Getting Started
Clone this repository.
Import the project into your preferred IDE (e.g., Android Studio).
Build and run the app on your device.
Enter a valid video URL and cast to your TV!
